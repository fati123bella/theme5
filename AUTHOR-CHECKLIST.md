# Content Creator SEO Checklist

Quick reference checklist for publishing recipe posts with optimal SEO.

## Pre-Publishing Checklist

### Title & Meta (2 minutes)
- [ ] Title is 50-60 characters
- [ ] Title includes recipe type keyword
- [ ] Title is descriptive and compelling
- [ ] Meta description written (155-160 chars)
- [ ] Meta description includes primary keyword
- [ ] Meta description has call-to-action

### Featured Image (3 minutes)
- [ ] Image uploaded (minimum 1200x630px)
- [ ] Image shows finished recipe/dish
- [ ] Image is high quality (not blurry)
- [ ] Image is properly licensed/owned
- [ ] Image alt text added: "Homemade [dish name] - [descriptor]"

### Recipe Content (10 minutes)
- [ ] Ingredients clearly listed and formatted
- [ ] Prep time filled in
- [ ] Cook time filled in
- [ ] Total time auto-calculated
- [ ] Yield/servings clearly stated
- [ ] Step-by-step instructions detailed
- [ ] Instructions are clear and actionable

### Body Images (5 minutes)
- [ ] Alt text added to all images
- [ ] Alt text is descriptive (not generic)
- [ ] Alt text includes relevant keywords naturally
- [ ] Images are compressed and optimized
- [ ] Images are at least 800px wide

### Categories & Tags (2 minutes)
- [ ] 2-3 relevant categories selected
- [ ] Categories match recipe type
- [ ] 3-5 descriptive tags added
- [ ] No duplicate categories

### Internal Linking (3 minutes)
- [ ] Link to 2-3 related recipes
- [ ] Link to category pages where relevant
- [ ] Use descriptive anchor text (not "click here")
- [ ] Links open in same tab (SEO preference)

### SEO Review (2 minutes)
- [ ] Title reads well and is keyword-focused
- [ ] First paragraph includes primary keyword
- [ ] Content naturally mentions related keywords
- [ ] No keyword stuffing (reads naturally)
- [ ] Structure uses headings (H2, H3) properly

## Quick SEO Tips

### Titles
- **Good:** "Easy Chocolate Chip Cookie Recipe - Chewy & Delicious"
- **Bad:** "Cookie Recipe"

### Meta Description
- **Good:** "Learn how to make perfectly chewy chocolate chip cookies at home. This easy recipe yields bakery-quality results in 30 minutes."
- **Bad:** "Chocolate chip cookies"

### Image Alt Text
- **Good:** "Homemade chocolate chip cookies on baking sheet with chocolate pieces"
- **Bad:** "cookie" or "image1"

### Internal Links
- **Good:** `<a href="/bread-recipes">easy bread recipes</a>`
- **Bad:** `<a href="/bread-recipes">click here</a>`

## Platform-Specific Tips

### For Google Search
- Focus on natural keyword usage
- Write clear, descriptive titles and descriptions
- Include cooking times and yield
- Use structured data (automatic)

### For Pinterest
- Use vertical images (1000x1500px)
- Create Pinterest-optimized descriptions
- Use 3-5 relevant keywords in pin description
- Link back to full recipe

### For Facebook/Instagram
- Use high-quality, appetizing images
- Write engaging captions
- Include recipe summary in post caption
- Use relevant hashtags (3-5 per platform)

### For Twitter
- Share recipe with key ingredients
- Use 1-2 relevant hashtags
- Encourage saves/shares
- Link to full recipe

## Common Mistakes to Avoid

❌ **Skip the featured image** - Images boost CTR by 30%+
❌ **Write vague titles** - "Recipe" doesn't rank; "3-Ingredient Brownie Recipe" does
❌ **Forget alt text** - Hurts accessibility and SEO
❌ **Stuff keywords** - Makes content unreadable
❌ **Publish without categories** - Helps organization and SEO
❌ **Use generic anchor text** - "Click here" doesn't help SEO
❌ **Poor image quality** - Affects user experience and bounce rate

## Keyword Research Quick Guide

### Finding Recipe Keywords

1. **Start with your recipe:** "Chocolate Chip Cookie Recipe"
2. **Check Google autocomplete:** Type phrase in Google, note suggestions
3. **Check People Also Ask:** Google shows common related questions
4. **Check search volume:** Use free tools like Google Keyword Planner
5. **Look at competitors:** Check top-ranking recipe sites

### Keyword Placement

For recipe "Easy Chocolate Chip Cookie Recipe":

- **Title:** Include "Chocolate Chip Cookie Recipe"
- **Meta description:** Include "easy" or "homemade"
- **First 100 words:** Natural mention of "chocolate chip cookies"
- **Headings:** Use recipe name or variations
- **Image alt text:** "Homemade chocolate chip cookies"
