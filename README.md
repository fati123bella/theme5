# CozyRecipes WordPress Theme

A simple, elegant, fully responsive WordPress recipe blog theme with Pinterest integration.

## Features

- **Modern Design**: Clean, minimal design with lots of white space, rounded corners, and subtle shadows
- **Pinterest Integration**: Pin It button on every image (hover on desktop, always visible on mobile)
- **Fully Responsive**: Mobile-first design that works perfectly on all devices
- **Hero Section**: Large hero banner with background image, search bar, and CTA button
- **Featured Recipes**: Showcase your best recipes in a dedicated section
- **Popular Categories**: Display recipe categories with icons and post counts
- **Responsive Navigation**: Mobile hamburger menu with support for multi-level dropdowns
- **Customizer Options**: Extensive customization options via WordPress Customizer
- **SEO Friendly**: Clean, semantic HTML5 markup
- **Fast Loading**: Optimized CSS and JavaScript
- **Widget Ready**: Multiple widget areas (sidebar + 3 footer columns)

## Installation

1. Download the theme files
2. Upload to `/wp-content/themes/` directory
3. Activate the theme through the WordPress admin
4. Go to Appearance > Customize to configure theme settings

## Customizer Options

### Colors
- Accent color (buttons, links, highlights)
- Header background color

### Hero Section
- Background image
- Tagline text
- Main heading
- Search placeholder text
- CTA button text and URL

### Featured Recipes Section
- Show/hide section

- Choose featured category

### Popular Categories Section
- Show/hide section
- Section title and subtitle

### Layout
- Sidebar position (left, right, or no sidebar)
- Container width (normal or wide)

## Pinterest Integration

The theme automatically adds a "Pin It" button to:
- All images in post content
- Featured images on single posts
- The button appears on hover on desktop
- Always visible on mobile devices
- Opens Pinterest share in a popup window

## Navigation

- Supports multi-level dropdown menus
- Responsive mobile menu (hamburger icon)
- Mobile menu slides in from the right
- Click outside or press ESC to close
- Full accessibility support with ARIA attributes

## Template Files

- `front-page.php` - Custom homepage with hero, featured recipes, and categories
- `index.php` - Main blog archive
- `single.php` - Single post template with related recipes
- `page.php` - Page template
- `archive.php` - Archive template
- `category.php` - Category archive with category icon
- `search.php` - Search results
- `404.php` - Error page
- `sidebar.php` - Sidebar widget area
- `header.php` - Site header
- `footer.php` - Site footer
- `comments.php` - Comments template

## Template Parts

- `template-parts/content-card.php` - Recipe card for grids
- `template-parts/content.php` - Standard post content
- `template-parts/content-none.php` - No results message
